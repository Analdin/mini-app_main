# AlfaDent — Mini App, FastAPI API и Telegram-бот

Это **основной репозиторий Mini App**. Он содержит:
- `web/miniapp.html`, `web/assets/` — интерфейс, фотографии клиники, карточки врачей и акции;
- `webapp_api.py` — FastAPI API, проверка подписи Telegram/MAX и общая авторизация;
- `bot_telegram.py` — Telegram-бот;
- `deploy/` — шаблоны systemd/Nginx и инструкция для собственного VPS.

MAX-бот находится отдельно: [Analdin/alfa-dent_max](https://github.com/Analdin/alfa-dent_max).

Старый репозиторий [alfadent-miniapp](https://github.com/Analdin/alfadent-miniapp) — прежняя копия проекта. Для новой установки используйте **только этот репозиторий** вместе с MAX-репозиторием, чтобы не запустить две разные версии API и не создать две базы аккаунтов.

## Авторизация

При первой регистрации API генерирует постоянный пароль. В базе хранится только PBKDF2-HMAC-SHA256 hash с уникальной солью. Вход: российский номер телефона + постоянный пароль. Сессия хранится на сервере в виде хеша токена; Mini App держит токен только в sessionStorage текущей вкладки. Telegram- и MAX-боты проверяют токен через общий API.

**Важное ограничение:** SMS/другого независимого подтверждения владения номером нет. Введённый номер сам по себе не доказывает, что он принадлежит пользователю. Не показывайте через такой вход медицинские документы или иные чувствительные данные до подключения независимой проверки номера.

## Установка

Инструкция по переносу на VPS с Ubuntu/Debian: [deploy/README_DEPLOY_RU.md](deploy/README_DEPLOY_RU.md).

Ключевые команды:
```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
uvicorn webapp_api:app --host 127.0.0.1 --port 8001
```

API обслуживает Mini App и статику. Telegram-бот запускается отдельно командой `python bot_telegram.py`. MAX-бот проксируется через Nginx на локальный порт 5000.

## Переменные окружения

Секреты не должны храниться в исходниках или Git. Храните их на VPS в закрытых файлах конфигурации systemd (права доступа не шире необходимых). Основные переменные перечислены в `deploy/alfadent.env.example`.

Не коммитьте токены, Bitrix24 webhook, прокси-пароли, базы SQLite, логи и каталоги `data/`.

## Поведение записи

Приложение создаёт обращение/лид в Bitrix24. Подтверждённую запись, реальный свободный слот и визиты из МИС «Инфоклиника» оно не имитирует: время подтверждает администратор клиники.
