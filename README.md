# AlfaDent — Telegram Bot и Mini App

Содержит Telegram-бота, Mini App и FastAPI API. Mini App/API предназначены для размещения на собственном VPS.

- `bot_telegram.py` — Telegram-бот.
- `webapp_api.py` — API Mini App, подписи запуска Telegram/MAX, единая авторизация.
- `web/miniapp.html`, `web/assets/` — интерфейс и медиа.

## Авторизация

Первичная регистрация создаёт постоянный пароль на сервере. Пароль показывается один раз, хранится в БД только как PBKDF2-HMAC-SHA256 hash с уникальной солью. Повторный вход выполняется по телефону и постоянному паролю. Общая база задаётся `AUTH_DB_PATH`. Для серверных вызовов ботов обязателен `INTERNAL_AUTH_SECRET`.

**Ограничение:** SMS/другого подтверждения владения номером нет. Нельзя считать введённый номер доказанным номером пациента или открывать медицинские/чувствительные данные до добавления независимой проверки.

## Запуск

Установите зависимости `pip install -r requirements.txt`. API: `uvicorn webapp_api:app --host 127.0.0.1 --port 8001`. Telegram: `python bot_telegram.py`. Для production используйте systemd/Nginx из общего пакета `alfadent-deploy`.

Переменные окружения и порядок переноса описаны в `alfadent-deploy/README_DEPLOY_RU.md`. Не коммитьте `.env`, токены, базы, логи и `data/`.

Приложение создаёт заявки в Bitrix24; подтверждённая запись и реальные слоты МИС не имитируются.
